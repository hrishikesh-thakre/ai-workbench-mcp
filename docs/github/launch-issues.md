Create a Goose recipe tuned for documentation-only changes, including a lightweight validation profile and quality-gate criteria.

## policy pack: low-risk coding validation

Add a reusable validation profile for low-risk coding tasks with starter commands and required evidence artifacts.

Expand `examples/tiny-python-fix/` into a complete narrated demo with before/after output and a sanitized accepted run.
