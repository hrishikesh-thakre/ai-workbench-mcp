# v0.6 PR Gate Adoption Hardening

Release-readiness note for package target `ai-workbench-mcp==0.6.0a0`.

Publication status: TestPyPI upload, PyPI upload, and exact-version install
proof completed on 2026-05-19. Do not publish MCP Registry without explicit release approval. The latest historical published package before this release was
`ai-workbench-mcp==0.3.0a0`.

## Scope

This alpha makes the external-repository PR gate adoption path installable and
boring.

Included repo assets:

- `ai-workbench-bootstrap --target .` for one-command external-repo setup.
- Packaged adoption assets for `.github/workflows/ai-workbench-pr-gate.yml`
  and `docs/ai-workbench-pr-gate.md`.
- Bootstrap output for `configs/`, `prompts/`, `recipes/`, and `.gitignore`
  with `runs/`.
- Backward-compatible `ai-workbench-bootstrap-assets` for configs, prompts,
  and recipes.
- Missing-evidence PR gate recovery steps in `pr_decision.json` and the PR
  comment.
- Bootstrap-first external setup docs and workflow template defaults targeting
  `ai-workbench-mcp==0.6.0a0`.

## Acceptance Rule

This release does not change acceptance semantics. A PR gate can report
`accept` only from real Workbench run evidence:

```text
validation_report.json
revision_decision.json
```

Missing evidence and scaffold fallback evidence still block with
`pr_gate.acceptance_evidence_missing`.

## Non-Goals

- No GitHub Checks API enforcement.
- No fork-comment strategy change.
- No GEPA or extra host integrations.
- No provider plumbing or provider cost enforcement.
- No Codex cloud evidence export.
