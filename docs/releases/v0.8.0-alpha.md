# v0.8.0 Alpha

Release-candidate note for the consolidation alpha package target
`ai-workbench-mcp==0.8.0a0`.

Publication status: not published to TestPyPI, PyPI, or MCP Registry.

This alpha consolidates local supervision, evidence capture, validation,
acceptance policy, and PR reporting into one AI Workbench product surface.

## Public Surface

- Package name remains `ai-workbench-mcp`.
- Product and public command are `AI Workbench` and `ai-workbench`.
- The MCP server is launched with `ai-workbench mcp serve`.
- Retired public console scripts are not installed:
  `ai-workbench-mcp`, `ai-workbench-bootstrap`,
  `ai-workbench-bootstrap-assets`, `ai-workbench-demo`, and `ai-gate`.

## Acceptance Contract

- `validation_report.json` and `revision_decision.json` are the final
  Workbench acceptance authority.
- Supervisor/local reports are supporting evidence.
- Supervised outcomes render as `accept`, `needs_review`, or `block`.
- The canonical local run ledger is `runs/<run_id>/`.

## Release Limits

- Supervisor, Codex hooks, and OpenCode watcher coverage are alpha mechanisms.
- High-risk work still requires human review.
- Do not upload this version without explicit release approval.
