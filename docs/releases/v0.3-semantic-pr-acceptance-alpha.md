## Scope

This alpha moves the public story from repo self-validation toward semantic PR acceptance backed by Workbench evidence.

Included repo assets:

- PR gate decision/comment behavior for `accept`, `needs_review`, and `block`.
- Scaffold-only fallback evidence blocking with `pr_gate.acceptance_evidence_missing`.
- First-class policy-pack catalog in `configs/policy_packs.yaml`.
- Five core policy packs: `docs_only`, `low_risk_bug_fix`, `test_fix`, `api_contract_change`, and `security_privacy_sensitive`.
- Copy-paste GitHub Actions template at `.github/workflows/ai-workbench-pr-gate.yml`.
- Package/bootstrap assets and `ai-workbench-bootstrap-assets` for configs, prompts, and recipes in the prepared `0.3.0a0` source build.
- One-page external repository setup guide at `docs/github/external-repo-setup.md`.
- Separate external sample repository proof plan at `docs/github/external-sample-repo-plan.md`.
- Sanitized PR gate outcome fixtures under `examples/pr-gate-outcomes/`.

## Acceptance Rule

A PR gate can report `accept` only from real Workbench run evidence:

```text
validation_report.json
revision_decision.json
```

Green CI, a sticky PR comment, uploaded workflow artifacts, and scaffold validation are not acceptance by themselves.
