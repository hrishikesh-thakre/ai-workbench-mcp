# v0.1.0-alpha

Release title:

```text
AI Workbench MCP: evidence-backed acceptance gates for Goose coding agents
```

## Scope

This alpha proves the first public Goose acceptance workflow:

- Goose-compatible stdio MCP server.
- Six MCP tools for run setup, model selection, execution capture, validation, quality gate, and run analysis.
- One engineering acceptance recipe.
- One tiny example task and one sanitized accepted sample run.
- Runtime MCP smoke coverage through the Python MCP SDK.

## Supported Workflow

```text
Goose performs task
  -> Workbench opens run
  -> Workbench records model response
  -> Workbench validates deterministically
  -> Workbench quality gate accepts, rejects, or requests review
  -> run folder proves what happened
```

## Known Limits

- Goose must be installed and configured separately.
- Recipe smoke depends on local Goose provider configuration.
- Local Gemma runs can be slow; use the two-tool smoke before the full acceptance recipe.
- Validation profiles are starter policies, not a broad policy pack library.
- Accepted-run analytics are local and file-based.
- MCP response contracts are stable enough for alpha use but not yet v1.0 API guarantees.

## Goose Smoke Commands

Two-tool smoke:

```bash
goose run --no-session --max-turns 4 --recipe ./recipes/workbench-mcp-tool-smoke.yaml \
  --params project=ai_workbench_mcp \
  --params run_dir=runs/goose-tool-smoke \
  --params task="Local Goose MCP tool smoke. Do not edit tracked files." \
  --params risk=low \
  --params complexity_score=4
```

Full six-tool smoke:

```bash
goose run --recipe ./recipes/workbench-engineering-acceptance.yaml \
  --params project=ai_workbench_mcp \
  --params run_dir=runs/goose-tiny-python-fix \
  --params task="Fix examples/tiny-python-fix/calculator.py so python -m unittest discover -s examples/tiny-python-fix -p test_*.py passes. Keep the change minimal and report the validation result." \
  --params task_type=implement \
  --params risk=low \
  --params validation_profile_override=tiny_python_fix \
  --params complexity_score=4
```
